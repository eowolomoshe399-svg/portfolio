## Project Structure

```
portfolio/
├── index.html                  # Main entry point (required at root for GitHub Pages)
│
├── assets/
│   ├── css/
│   │   ├── style.css           # Base styles, variables, layout, components
│   │   ├── animations.css      # Keyframes, scroll reveal, cursor, orb drift
│   │   └── responsive.css      # Mobile/tablet breakpoints (max-width: 900px)
│   │
│   ├── js/
│   │   ├── cursor.js           # Custom dot + ring cursor with hover states
│   │   └── animations.js       # Scroll reveal via IntersectionObserver
│   │
│   └── images/                 # Profile photo, project screenshots (add as needed)
│
├── pages/                      # Reserved for future dedicated pages
│
└── README.md
```

## Tech Stack

- **HTML5** — semantic structure

- **Vanilla JavaScript** — cursor logic, scroll reveal
- **Google Fonts** — Playfair Display, Outfit, JetBrains Mono
